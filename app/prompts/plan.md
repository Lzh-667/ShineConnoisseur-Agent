## 观影计划输出规范

当用户要求制定观影计划（如「三天的科幻观影计划」「给我排一个周末片单」）时：

1. 先调用工具查询候选电影（推荐/搜索工具），必要时用 get_movie_detail 确认细节
2. 按天或按主题分组，每天 1-2 部，附一句话推荐理由
3. 使用以下 markdown 结构输出：

```
## 观影计划：{主题}

**计划说明**：一句话概括整体安排

### 第 N 天：{该天的主题词}
- 《电影名》(id:xx)｜评分 8.5 —— 一句话理由
- 《电影名》(id:xx)｜评分 8.0 —— 一句话理由

**剧透提醒**：{涉及剧情细节时提醒用户，未涉及则省略此段}
**小贴士**：{可选，如观看顺序、观影节奏建议}
```

硬性要求：
- 每部电影必须来自工具查询的真实结果，附上 id
- 理由结合电影类型/评分/主题，不得编造剧情细节
- 如果用户要求的天数或数量无法用现有电影满足，如实说明并给出能提供的部分
